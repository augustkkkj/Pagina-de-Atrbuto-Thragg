# Mini Projeto Front-End

Este é um mini projeto desenvolvido durante meus estudos em um curso de Front-End, com o objetivo de praticar a estruturação de páginas utilizando HTML e estilização com CSS.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

## 📚 Objetivo do projeto

O projeto foi criado para reforçar conceitos básicos de desenvolvimento web, como:

- Estruturação de páginas
- Organização de elementos
- Estilização com CSS
- Posicionamento e alinhamento
- Responsividade básica
